# Правила проекта

- Бизнес-требования описаны в README; сохраняй HTTP-коды и формат ответов задания.
- Все деньги — целые копейки. Не используй float для сумм и скидок.
- API проверяет запрос и передаёт команду Redis. ORM и бизнес-обработка находятся у worker.
- Изменение платежа и результат команды должны коммититься в одной транзакции PostgreSQL.
- Идемпотентность защищается уникальным ограничением БД, смена статуса — блокировкой строки.
- Пиши небольшие функции с понятными именами. Комментарии объясняют причину решения.
- Проверяй существенные изменения через Ruff и pytest с настоящими PostgreSQL и Redis.
- В AI_LOG.md записывай только реальные запросы, ошибки и выполненные проверки.
