`Тестовое_Junior_Python_FastAPI.pdf`. ИИ помог с реализацией, тестами и проверками.

Смысл реальных запросов пользователя, отредактированный для читаемости:

1. «Посмотри тестовое Junior Python / FastAPI» — передан путь к PDF; извлечены правила
   денег, рассрочки, идемпотентности, статусов и обязательные сценарии тестирования.
2. «Сделай PostgreSQL, передачу запросов через Redis, отдельный обработчик, Docker
   и CI со всеми тестами» — этот контекст определил разделение API и worker.
3. «Оформи мои запросы в AI_LOG.md и сделай код понятным, чтобы я могла разобраться» —
   алгоритмы вынесены в отдельный модуль, в README добавлен порядок чтения файлов.
4. добавить CD для проекта. сделать проект в докере Debian. 
5. добавть в README запуск проекта без образа докера. тоесть для быстрой ручной проверки с requirements
6. микросервесы со связью через Redis.


## предложения и проверка

Первая схема ассистента использовала Redis для фоновых событий, оставляя обработку
в API. Это расходилось с запросом на передачу обработки через Redis. Схема исправлена:
команда и результат проходят через Redis, синхронное ожидание сохраняет HTTP-коды ТЗ.

Неоднозначное описание сервисов было явно трактовано как четыре контейнера
(`api`, `worker`, `redis`, `postgres`), одна БД и возврат HTTP-ответа через API.

Реальная ошибка ассистента: обычный `sqlalchemy` не установил нужный async-модулю
`greenlet`. Первый pytest упал с `ImportError`. Зависимость заменена на
`sqlalchemy[asyncio]`, lock-файл обновлён, тесты и запуск контейнеров повторены.

**Проверка результата:** 88 сценариев прошли локально, в Docker и после установки
requirements через pip в чистое окружение, с настоящими PostgreSQL и Redis. Проверены
копейки, ответы, все переходы, гонки двух worker, восстановление команд и HMAC.
Ruff, форматирование и actionlint прошли. Четыре контейнера запущены; HTTP-проверки
создания, повторов, вебхуков и `404` успешны. По дальнейшим запросам добавлены
requirements и доставка образа в GHCR после CI. Запуск на GitHub и публикация в этой
сессии не выполнялись. Замечания пользователя и его личные проверки не выдумывались.
